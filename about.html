About me

Building useful software with curiosity and purpose.

I’m a Computer Information Systems student and emerging software engineer in New York who enjoys understanding systems, solving practical problems, and building useful technology.

My direction

Software with a security mindset

I build tools that make technical workflows easier to understand and manage—from browser-based public-data research to natural-language systems software and institutional workflow platforms.

Software engineering is my primary direction, strengthened by a security mindset. I’m especially interested in cloud infrastructure, applied AI, secure system design, and the Microsoft technology ecosystem. C# and Azure are my next learning focus as I work toward building reliable applications and cloud services.

How I learn

From theory to working systems

I learn by building applications, developer tools, virtual environments, and networked systems—then testing assumptions and troubleshooting what fails.

I’m also deliberately improving my communication, documentation, teamwork, and decision-making because useful software requires understanding people and tradeoffs, not only writing code. AI helps me move faster, but I use it to support reasoning rather than replace technical understanding.
